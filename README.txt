Datasets go in this folder. Run  python download_datasets.py  from the project folder and it
will place these exact files here:

  diabetes.csv                  (Pima Indians Diabetes)
  heart_cleveland.data          (UCI Heart Disease, Cleveland)
  chronic_kidney_disease.arff   (UCI Chronic Kidney Disease)
  ilpd_liver.csv                (UCI Indian Liver Patient Dataset)
  parkinsons.data               (UCI Parkinsons)

Breast cancer needs no file: it is bundled with scikit-learn.
